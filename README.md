# BreatheWise AI 🌍
### Your Personal Urban Air Quality Intelligence Assistant

## 1. About the Project
BreatheWise AI is an AI-powered web application designed to help people understand air pollution and make informed decisions about their environment.

It provides air-quality information, forecasts, city comparisons and an AI chatbot that explains pollution-related topics in simple language.

## 2. Problem Statement
Air pollution is a major environmental concern. Many people find it difficult to understand AQI values and the effects of pollutants.

BreatheWise AI aims to make air-quality information easier to understand and more accessible.

## 3. Key Features
- Real-time estimated air-quality information.
- AQI dashboard.
- PM2.5, PM10 and NO₂ information.
- Seven-day air-quality forecast.
- City comparison.
- AI-powered chatbot.
- Daily air-quality tips.
- Eco Tracker for tracking positive habits.
- Mobile-friendly design.

## 4. Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Google Gemini API
- Open-Meteo Air Quality API

## 5. How It Works
1. The user searches for a city.
2. The application retrieves estimated air-quality information.
3. The dashboard displays AQI and pollutant details.
4. The forecast section displays estimated future air quality.
5. The AI chatbot answers air-pollution questions.
6. The Eco Tracker encourages environmentally responsible habits.

## 6. Installation and Setup

### Requirements
- Node.js
- Visual Studio Code
- Internet connection

### Backend Setup
1. Open the project folder in VS Code.
2. Open the terminal.
3. Install dependencies using:

   npm install

4. Create a `.env` file and add your Gemini API key:

   GEMINI_API_KEY=your_api_key_here

5. Start the backend:

   node server.js

### Frontend Setup
1. Open `index.html` in VS Code.
2. Run it using the Live Server extension.
3. Open the website in your browser.

## 7. Data Sources
